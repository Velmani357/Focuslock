# 🔒 FocusLock

**FocusLock** is a web-based distraction alert tool that helps users stay focused during their study sessions. By tracking tab activity and alerting users when they switch away from the study tab, FocusLock boosts concentration and productivity.

## 🧠 Inspiration

Online study is full of distractions — a single tab switch can lead to hours lost. FocusLock was built during United Hacks to provide students with an accountability tool that actively monitors and encourages focus.

## 🚀 What It Does

- ✅ Lets users set a **study URL** and **study duration** (in minutes)
- 🔗 Opens the study page in a new tab/window
- 🔔 Alerts with sound if user switches away from the study window
- ⏱️ Tracks **how long you were distracted**
- 🧾 Shows session summary at the end

## 💻 Tech Stack

- HTML
- CSS (for clean UI)
- JavaScript (vanilla, no libraries)
